# Projeto-academico-Notas-do-Futuro
Projeto acadêmico desenvolvido em equipe na disciplina de Banco de Dados.
Objetivo do projeto: Criar um site de jogos educativos para inetivar crianças e adolescentes em seu aprendizado sobre a cultura de diverssas regiões do Brasil, o site oferece atividades prontas, com instruções simples que os professores podem aplicar diretamente sem a exigência de uma preparação prévia.
A plataforma foi pensada para uso imediato em sala, com materiais prontos e linguagem acessível utilizando ferramentas aprendidas até então em nosso curso.
